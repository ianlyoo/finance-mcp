# Tools

28 tools on one server; names and argument schemas are identical over stdio and HTTP. Internal compatibility helpers cannot be called as MCP tools.

Only the curated 21 finance tools and 7 research tools are registered. General quotes/candles, public financials, ECB FX (get_market_info with include=["fx"]), Binance market data and research need no broker key. Optional broker sections require your own keys. Demo mode covers account and portfolio tools with a generated 30-day history; local statement import requires a configured account.

Unless marked **local write**, tools are read-only at the MCP boundary. Reads may cache provider data or record observations locally. No tool can submit a financial transaction. Optional arguments show defaults; `required` means no default.
